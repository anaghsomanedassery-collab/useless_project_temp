### Project Description
Mirrorception is a completely useless website that solves a problem nobody has ever had: checking whether the person sitting in front of a mirror is also sitting in front of a mirror.

Click on the mirror, zoom in, and discover another version of the same person sitting in front of another mirror... and another... and another. A completely pointless infinite loop of mirrors and productivi

### The Problem (that doesn't exist)
Have you ever looked into a mirror and wondered:

"What if the person inside the mirror is also looking into a mirror?"

No?

Exactly.

But clearly, this is a problem that desperately needed a technological solution.

People around the world are wasting valuable seconds looking at normal mirrors without knowing what happens inside the reflection. Mirrorception fixes this completely unnecessary inconvenience.

### The Solution (that nobody asked for)
We created an interactive website where a person is sitting in front of a computer and a mirror.

When the user clicks on the mirror:

The camera/view zooms into the mirror.

The same person appears inside the reflection.

That person is sitting in front of another mirror.

Clicking that mirror zooms in again.

The cycle continues.

Essentially, we built an infinite mirror loop for absolutely no reason.

### Implementation
For Software:For Software
The website consists of an interactive scene containing:

A person sitting in front of a computer

A mirror positioned in the scene

An interactive mirror area

A zoom transition when the mirror is clicked

A recursively repeating mirror scene

Visual effects to create the illusion of an endless reflection

The main interaction follows the concept:

User opens website
       ↓
Person sitting at computer
       ↓
User clicks the mirror
       ↓
Camera zooms into mirror
       ↓
Same scene appears inside mirror
       ↓
Another mirror is visible
       ↓
User clicks again
       ↓
ZOOM
       ↓
Repeat forever
